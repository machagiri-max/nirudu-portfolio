# Nirudu Portfolio (React + Vite + Three.js)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

Edit your links and content in `src/data.js` (search for TODO to add LinkedIn and GitHub, and set the `live` / `code` URLs for each project).
Deploy the `dist` folder on Vercel or Netlify.
